# Code of Conduct · ميثاق السلوك

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and patient. Harassment, insults, and personal or political attacks are not tolerated. Critique ideas, not people.

باختصار: كن محترماً ومرحِّباً وصبوراً. لا نقبل التحرش أو الإهانة أو الهجوم الشخصي. انتقد الأفكار لا الأشخاص.

Report unacceptable behaviour privately to the maintainer via a [GitHub security advisory](https://github.com/almhdy24/sigma/security/advisories/new) or by contacting [@almhdy24](https://github.com/almhdy24). Reports are handled confidentially.
