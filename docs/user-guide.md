## البدء

عند فتح سيغما لأول مرة تظهر ثلاثة خيارات:

|---|---|
| **جرّب ببيانات مثال** | يحمّل بيانات 50 مريضاً (العمر، الجنس، التشخيص، ضغط الدم، مؤشر كتلة الجسم) لتجربة كل التحليلات فوراً |
| **استيراد ملف** | يفتح ملف CSV أو Excel من جهازك |

## تثبيت التطبيق على الجوال

- **أندرويد (Chrome):** يظهر شريط «تثبيت سيغما» بعد قليل. أو افتح القائمة ⋮ ← **تثبيت التطبيق**. يمكنك أيضاً تثبيته من **Google Play** عند إتاحته.
- **آيفون (Safari):** زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.
- **الحاسوب (Chrome / Edge):** أيقونة التثبيت في شريط العنوان.

## المتغيرات والبيانات

### عرض المتغيرات
لكل متغير:
- **الاسم:** حروف إنجليزية وأرقام و `_` فقط، ويبدأ بحرف (مثل `age`). يُستخدم في الصيغ.
- **التسمية:** الاسم الظاهر بأي لغة (مثل «العمر»).
- **النوع:** رقمي، نصي، فئوي، تاريخ.
- **مستوى القياس:** اسمي، ترتيبي، كمّي.
- **تسميات القيم:** مثل `1 = ذكر` و `2 = أنثى`.
- **القيم المفقودة:** رموز تُعامَل كمفقودة (مثل `99`).

### عرض البيانات
- **الحاسوب:** جدول مثل Excel. انقر خلية ثم اكتب، أو اضغط Enter أو انقر مرتين للتعديل. تنقّل بالأسهم و Tab. **Ctrl+Z** للتراجع و **Ctrl+Y** للإعادة.
- **الجوال:** كل حالة بطاقة. اضغط عليها للتعديل، وزر **+** لإضافة حالة.

البيانات تُحفظ تلقائياً على جهازك.

## الاستيراد والتصدير

- **الاستيراد:** CSV و Excel (`.xlsx`). يقترح سيغما نوع كل عمود، ويمكنك ربط الأعمدة بمتغيرات موجودة أو تخطّيها، واختيار استبدال البيانات الحالية أو إضافتها. الأعمدة ذات الأسماء العربية تأخذ أسماء مثل `var1` مع حفظ الاسم العربي كتسمية.
- ملفات Excel القديمة (`.xls`) غير مدعومة: احفظها بصيغة `.xlsx` أولاً.
- **التصدير:** CSV (يفتح بالعربية بشكل سليم في Excel) أو Excel. ومن عرض المتغيرات: **تصدير دليل البيانات** بصيغة PDF.

## تحويل البيانات

| الأداة | الاستخدام |
|---|---|
| **حساب متغير** | متغير جديد من صيغة، مثل `round(weight / (height/100)^2, 1)` لمؤشر كتلة الجسم. الصيغة تدعم `+ - * / ^`، المقارنات، `and`/`or`، الشرط `أ ? ب : ج`، والدوال `sqrt` و `log` و `ln` و `exp` و `round` و `min` و `max` و `mean` و `sum`. إن كانت أي قيمة مفقودة تبقى النتيجة مفقودة |
| **إعادة ترميز** | تحويل قيم أو مجالات إلى قيم جديدة (مثل العمر ← فئات عمرية) |
| **اختيار الحالات** | قصر التحليلات على مجموعة جزئية (مثلاً الإناث فقط) |
| **تقسيم الملف** | تشغيل كل تحليل منفصلاً لكل مجموعة |

## التحليلات الإحصائية

| التحليل | متى تستخدمه |
|---|---|
| **الإحصاء الوصفي** | المتوسط، الوسيط، الانحراف المعياري، الالتواء، التفلطح، القيم الشاذة |
| **جداول التكرار** | توزيع متغير فئوي |
| **الجداول التقاطعية** | العلاقة بين متغيرين فئويين (كاي تربيع، Cramér's V) |
| **معاملات الارتباط** | العلاقة بين متغيرات كمّية (بيرسون وسبيرمان) |
| **اختبار t** | مقارنة متوسطين: عينة واحدة، مستقلتان، مترابطتان. مع فحص الافتراضات والبدائل اللامعلمية |
| **تحليل التباين الأحادي** | مقارنة ثلاث مجموعات أو أكثر، مع اختبار توكي البعدي وكروسكال-واليس |
| **الانحدار الخطي المتعدد** | التنبؤ بمتغير كمّي، مع معامل تضخم التباين VIF |
| **الاختبار التشخيصي** | الحساسية، النوعية، القيم التنبؤية |
| **منحنى ROC** | دقة متغير كمّي في التمييز بين حالتين (AUC) |
| **الثبات (α)** | ألفا كرونباخ لمقياس أو استبيان |

لكل تحليل زر **؟** يشرح متى يُستخدم وافتراضاته وكيف تقرأ نتائجه.

### التنزيل حسب الحاجة
الحسابات تتم بمكتبات Python العلمية (NumPy و SciPy) داخل جهازك. عند أول تشغيل لتحليل يُنزَّل الجزء الذي يحتاجه فقط، مع شريط تقدّم وزر إلغاء:

| الجزء | الحجم التقريبي | يحتاجه |
|---|---|---|
| نواة بايثون | 13.8 MB | كل التحليلات (عدا الاختبار التشخيصي) |
| NumPy | 3.6 MB | الثبات، ROC |
| SciPy | 15 MB | بقية التحليلات |

بعد التنزيل الأول تعمل هذه الأجزاء دون إنترنت. لتنزيل كل شيء مرة واحدة: تبويب **تحليل** ← **تنزيل كل شيء للعمل دون إنترنت**.

## الرسوم البيانية

المدرَّج التكراري، الرسم الشريطي، مخطط الانتشار، ومخطط الصندوق والشارب (مع متغير تجميع اختياري). زر **تنزيل PNG** يحفظ الرسم كصورة.

## النتائج وملفات PDF

- كل نتيجة تُحفظ في تبويب **النتائج** وتبقى بعد إغلاق التطبيق.
- **نسخ:** نسخ الجداول كنص (للصق في Word أو Excel).
- **تصدير PDF:** لنتيجة واحدة أو لكل النتائج في تقرير، بالعربية والإنجليزية.
- كل نتيجة تتضمن **فقرة المنهجية** بأسلوب APA (بالإنجليزية) جاهزة للرسالة أو البحث.

## العمل دون إنترنت

- الواجهة تعمل دون إنترنت بعد أول زيارة.
- كل شاشة أو تحليل استخدمته مرة يبقى محفوظاً.
- لضمان عمل كل شيء دون إنترنت: **تحليل ← تنزيل كل شيء للعمل دون إنترنت** (حوالي 33 MB مرة واحدة).

## أسئلة شائعة

**هل تُرسَل بياناتي إلى أي مكان؟**
لا. كل شيء يبقى على جهازك. راجع [سياسة الخصوصية](../public/privacy.html).

**هل النتائج دقيقة مثل SPSS؟**
الحسابات تستخدم SciPy و NumPy، وهي المكتبات العلمية المرجعية في بايثون، ونتائجها مطابقة لـ SPSS في الاختبارات القياسية. الاختبارات الآلية تقارن نتائج سيغما بقيم مرجعية.

**كيف أنقل بياناتي لجهاز آخر؟**
صدّرها كملف Excel، ثم استوردها في الجهاز الآخر.
